# 📁 File Manager

A simple CRUD (Create, Read, Update, Delete) File Manager built using Python and Streamlit.

This project was created while learning Python to understand how file handling works and how those concepts can be transformed into an interactive web application.

## ✨ Features

- 📄 Create new text files
- 👁️ Read the contents of existing files
- ✏️ Update files by:
  - Appending new content
  - Renaming files
  - Overwriting existing content
- 🗑️ Delete files with confirmation prompts
- 🌙 Dark/Light theme toggle
- 🎨 Clean and beginner-friendly user interface built with Streamlit

## 🚀 Getting Started

### 1. Clone the repository

bash git clone https://github.com/thepratikyadava/File-handling-.git cd File Handling 

### 2. Install dependencies

bash pip install streamlit 

### 3. Run the application

bash streamlit run app.py 

The application will open automatically in your browser.
